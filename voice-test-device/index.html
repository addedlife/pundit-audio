    How to get the best voices on the iPad

    Open Settings → Accessibility → Spoken Content → Voices → English. Choose United Kingdom (or United States) and download a voice marked Enhanced or Premium (for British male, try Daniel, Oliver or Arthur where offered). Tap the voice once so it finishes downloading (it is large, so use Wi-Fi). Then fully close Safari, reopen this page, and the voice should appear in the list above.

    Honest limits: Safari decides which voices a web page may use. Premium and Enhanced voices normally show up; the Siri-branded voices sometimes do not, and Personal Voice never does. If a voice you downloaded is missing from the list above, that is Safari, not this page. The page shows exactly what Safari reports under "All voices this browser reports".

    iOS rules: (1) Speech only starts from a tap on this page, so this cannot start by itself at 7 AM; (2) keep the screen on and Safari in front, because iPadOS may stop speech when the screen locks or the tab is in the background; (3) the music uses the same tap permission, so it can follow the reading, but if Safari ever blocks it, tap "Skip to music". (4) Pause is implemented as a stop and restart of the current sentence, because iPad's native pause is unreliable.
