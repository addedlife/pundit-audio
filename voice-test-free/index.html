Chatterbox (Resemble AI, open source, MIT)Installed and ran here on CPU, about 2× slower than real time, so a 10-minute brief would take about 20 minutes. Its built-in default voice is not a male newsreader; a male voice needs a reference recording (voice cloning), which counts as cooking a voice, so no sample is shown.
Chrome “Google UK English Male”Not usable. Chrome on Linux and headless Chrome expose no voices (I checked: the list was empty). On a desktop it only plays live in that browser; there is no sanctioned way to record it. Chrome on the iPad uses Apple’s voices, the same as Safari.
Google Translate speechUnofficial endpoint, against Google’s terms, 200-character chunks, older robotic voice. Skipped.
Edge HD / DragonHD / Ollie MultilingualNot offered by the free Edge service. I tried en-GB-OllieMultilingualNeural and a DragonHD name and both failed. Those are paid Azure-only voices.
ElevenLabs freeFree signup, no card, but only 10,000 characters a month (about 10 minutes, one brief). The free plan is non-commercial and requires attribution, and library voices cannot be used through the API. Not enough for daily briefs.
Cartesia freeFree signup, no card: 20,000 credits a month, about 27 minutes of audio, non-commercial. That covers about 2–3 briefs a month.
Google Cloud, Azure free tiersBoth need a card or billing account. Excluded.
F5-TTS, XTTS-v2Both need a reference recording (voice cloning), and both have non-commercial model licences. Excluded as cooking a voice.
Orpheus, Sesame CSM, Dia1–3 billion parameter models built for GPUs; far too slow on this CPU-only box.
StyleTTS2Older research model; Kokoro is built on its architecture and is the better choice.
